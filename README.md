# Electro – E‑Commerce Website

[Live Demo](https://electro-iti.netlify.app/) • [GitHub Repository](https://github.com/ibrahimeltbakh/Electro)

Electro is a modern e‑commerce platform for selling electronics, featuring AI‑powered product comparison, voice and text search, and a fully responsive design. The platform includes both user‑facing and admin functionalities.

## Features

### User Features
- **Home Page**: Engaging UI with featured products.
- **Shop**: Filtering, sorting, search with text and voice input, and AI product comparison.
- **Wishlist**: Save favorite products for later.
- **Categories & Brands**: Browse products by category or brand.
- **Cart & Checkout**: Add products to cart and complete purchase.
- **Profile**: Manage orders, edit profile information.
- **Dark & Light Modes**: User‑selectable themes.

### Admin Features
- **Dashboard**: Access for admins only.
- **Product Management**: Add, edit, delete products.
- **Category & Brand Management**: Add, edit, delete categories and brands.
- **Coupons Management**: Add, edit, delete discount coupons.

## Tech Stack
- **Frontend**: ReactJS, Tailwind CSS, Framer Motion, Radix UI  
- **State & Data Handling**: React Query, React Hook Form  
- **UI Components & Animations**: Lucide React, AOS, Slick Carousel, Tailwind Variants  
- **Backend & APIs**: Axios, OpenAI (for AI comparison)  
- **Notifications & Alerts**: React Hot Toast, SweetAlert2, React Toastify  
- **Build Tools**: Vite, ESLint, TypeScript  
- **Other**: Dark/Light Mode support, Voice Search, Responsive Design

Home – Landing page for products.
